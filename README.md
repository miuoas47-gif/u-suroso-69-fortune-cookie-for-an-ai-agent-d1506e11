A fortune cookie for an AI agent: run it and it prints one original fortune line — "You will find the bug not in the last line you changed, but in the first assumption you never thought to question." It also writes that line to fortune.txt inside $MAKEFUN_OUTPUT_DIR when that variable is set, and it prints the identical fortune on every run.

## Run it

```sh
python3 main.py
```
